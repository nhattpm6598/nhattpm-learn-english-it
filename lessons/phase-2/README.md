## Mỗi file tuần gồm

1. **Mục tiêu tuần**
2. **Mẫu câu chính** — chia nhóm, có nghĩa và tình huống dùng
3. **Hội thoại mẫu** — 2–3 đoạn để đọc to và shadowing
4. **Từ vựng** — bảng từ / IPA (Mỹ) / nghĩa / ví dụ
5. **Ngữ pháp nhanh** — một điểm ngữ pháp chủ đề cần, kèm 5 bài tập
6. **Câu hỏi luyện nói** — 10–15 câu, có câu trả lời mẫu
7. **Kịch bản cho buổi gia sư / AI** — prompt dán thẳng vào AI chế độ giọng nói, việc cần hỏi gia sư
8. **Tài liệu nghe / xem** — link kênh, chuyên mục và từ khóa để tìm
9. **Đáp án**

## Cách dùng trong tuần

| Ngày | Dùng phần nào |
| --- | --- |
| T2 | Đọc mục 1–2, shadowing hội thoại 1 (mục 3), thêm 10 từ từ mục 4 vào Anki |
| T3 / T6 (gia sư) | Mở mục 7, nói với gia sư đúng kịch bản; chép lỗi vào `log/vocabulary.md` |
| T4 | Làm bài tập mục 5, tự trả lời 5 câu ở mục 6 và ghi âm |
| T5 | Dán prompt ở mục 7 vào AI, nói 10–15 phút |
| T7 | Ôn từ, nghe lại bản ghi âm, so với câu trả lời mẫu, viết nhật ký tuần |

Mẹo: câu trả lời mẫu chỉ để tham khảo. Hãy **thay bằng thông tin thật của bạn**, rồi lưu bản tốt nhất vào `interview/answers.md` — nhiều câu (giới thiệu bản thân, công việc, chuyện STAR) sẽ dùng lại ở giai đoạn 4.
