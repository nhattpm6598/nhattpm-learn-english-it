# Tài nguyên

> Danh sách dựa trên hiểu biết chung, chưa kiểm tra giá tại thời điểm viết (10/2026).

| Tài nguyên | Dùng cho | Giai đoạn | Chi phí |
| --- | --- | --- | --- |
| Anki + bộ Oxford 3000 | Từ vựng, ôn lặp lại ngắt quãng | 1–4 | Miễn phí (Anki iOS có phí) |
| *English Grammar in Use* (Raymond Murphy) | Ngữ pháp | 1–2 | Mua sách |
| Rachel's English (YouTube) | Phát âm, shadowing | 1–2 | Miễn phí |
| ELSA Speak | Chấm phát âm | 1–2 | Có bản miễn phí, bản trả phí |
| Từ điển Cambridge / Oxford online | Tra IPA, nghe phát âm | 1–4 | Miễn phí |
| BBC Learning English (6 Minute English) | Nghe | 1–2 | Miễn phí |
| VOA Learning English | Nghe chậm | 1 | Miễn phí |
| Cambly, Preply, italki | Nói với gia sư | 2–4 | Trả theo buổi hoặc gói |
| Claude / ChatGPT chế độ giọng nói | Luyện nói, sửa lỗi, phỏng vấn thử | 2–4 | Miễn phí hoặc trả phí |
| Fireship, ByteByteGo (YouTube) | Nghe và shadowing nội dung IT | 3–4 | Miễn phí |
| GOTO Conferences, InfoQ | Talk kỹ thuật dài | 3–4 | Miễn phí |
| Grammarly | Kiểm tra bài viết | 3–4 | Miễn phí / trả phí |
| LeetCode | Luyện coding interview nói to | 4 | Miễn phí / trả phí |
| EF SET | Đo trình độ đầu và cuối | 0, 39 | Miễn phí |

## Prompt mẫu khi luyện với AI

```
You are my English tutor. I'm a Vietnamese software engineer at A2 level.
Talk with me about <topic>. Use simple English, ask one question at a time.
After every answer, correct my mistakes briefly, then continue.
```

```
Act as a technical interviewer for a Senior Java Software Engineer role.
Ask me one question at a time. After I answer, give feedback on my English
and my content, then ask the next question.
```
